## Brief One-Line Summary  
An interactive Power BI dashboard to monitor ATM transactions, uptime, and performance across multiple branches.  

---

##  Overview  
This project demonstrates the use of **Power BI** for ATM analytics. The dashboard provides actionable insights on **transaction volumes, downtime, cash withdrawals, and error patterns** across a network of ATMs.  

---

## Problem Statement  
ATM operations generate huge amounts of log data, but analyzing them in spreadsheets is inefficient.  
Challenges include:  
- Detecting **underperforming ATMs**  
- Tracking **uptime/downtime** effectively  
- Understanding **cash usage patterns**  
- Optimizing **maintenance and replenishment schedules**  

This dashboard simplifies monitoring and enables **data-driven decision-making**.  

---

## Data Collection
Data was collected from various sources including ATM transaction logs, maintenance records, and financial reports. The data was cleaned and prepared for analysis using data preprocessing techniques.

---


## Tools and Technologies  
- **Power BI Desktop** → dashboard creation, DAX measures, visualizations  
- **Excel / CSV / SQL** → data source / preprocessing   

---

## Methods  
1. **Data Cleaning** in Power Query  
2. **Data Modeling** → relationships across ATMs, branches, and dates  
3. **DAX Measures** for uptime %, avg transactions, etc.  
4. **Visuals** → KPIs, line charts, bar charts, slicers, filters  
5. **Interactivity** → branch, ATM ID, and date filters  

---

## Key Metrics
- Total Cost: 296M
- Average Total Transactions (TXN): 178.89M
- Gross Profit Percentage: 59.6%
- Average Uptime: 91.9%
- Average EBILL: 2.21K

## Results & Conclusion

This dashboard transforms raw ATM logs into business insights:

- Reduces downtime through proactive monitoring
- Improves customer experience by ensuring cash availability
- Optimizes maintenance scheduling
- Helps allocate resources across branches efficiently
